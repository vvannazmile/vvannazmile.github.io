Install in three steps

DownloadGet the installer using the button above. It's one file.
Run the installerFollow the setup window. If your PC doesn't have the Microsoft Edge WebView2 Runtime yet, setup installs it for you.
Open WannaSmileStart it from the Start Menu. It opens in its own window and loads the site.

Good to know

Internet is requiredThe app fetches the live site, its data and its assets from the internet each time. It does not work offline. If it can't connect, it shows a message with a Retry button.
Same WannaSmileYour library, settings and ticket work the same way as in the browser, but the app keeps its own saved data, separate from your browser's: use Export in the browser and import it in the app to move your ticket over. Links to other websites open in your normal browser.
WebView2 RuntimeThe app is built on Microsoft's Edge WebView2. The Runtime is a separate Microsoft component that setup installs only if it's missing.
