Project Updates

Release notes and development updates for WannaSmile.

✨Recent updates

💬

Direct messaging

WannaChat supports friend requests, direct messages, typing indicators, and in-app notifications.

🔔

Unread message indicators

The header message icon indicates when a direct message is unread. Names and profile images are shown in conversations.

📚

Library updates

Assets have been re-added across pages 11 through 15 of the library, so those pages are filled back in and ready to browse, search and favorite.

🎟️

Account registration

New users can register with a username, email address, and password. Email addresses are not verified and are used to prevent duplicate registrations.

📣

Project update notifications

A project update notice appears when a new update is detected. Dismissing it keeps the notice closed until another update is available.

🎀

Library structure and content

The homepage structure has been revised, and Prodigy content has been added to expand the available library. The collection includes versions released before its recent redesign.

🍂

Seasonal assets

Halloween- and autumn-themed assets have been added. Planned additions include GIF packs, a custom cursor, and six cursor trail styles for the store.

❄️

Planned seasonal updates

Planned winter additions include themed assets, GIF packs, custom cursors, and seasonal trails for the store.

Development outlook

Development may pause in 2027 while the maintainer focuses on other programming work. A future ownership transfer is being considered, but no timeline has been set.
